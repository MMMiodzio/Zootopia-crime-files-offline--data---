Currently, this is the only preserved and publicly available mod for Zootopia: Crime Files where all cases are fully functional. (While I haven't had the chance to test every single case end-to-end, the game files indicate that they all work.)

- Installation Instructions:

- Download and install the official APK file.

- Place the OBB file in the correct directory.
-
Replace the data folder. (Note: On newer Android models, you will need to perform the file transfer using a PC).

Compatibility: with the Samsung Galaxy S23 and older devices.  (Snapdragon 8 Gen 3 and newer, not supported)

Disclaimer: The original files originate from a not, defunct mod that unlocked all cases. I am not the original author of this mod I am simply archiving and sharing these files for game preservation so that dedicated fans can still enjoy the game.
